# Nagaraj B M — Cinematic Portfolio V4 (Android optimized)

V4 keeps the cinematic desktop experience and adds a touch-first Android/mobile layout:
- Android Chrome responsive portrait layout
- small-screen typography
- touch-friendly interactions
- desktop custom cursor disabled on touch
- desktop 3D tilt disabled on touch for smoother mobile performance
- responsive project visuals
- safe text wrapping and tap targets
- landscape phone support

Run with VS Code + Live Server:
1. Extract ZIP.
2. Open folder in VS Code.
3. Install Live Server.
4. Right-click `index.html` → Open with Live Server.

Test on Android:
- Open the Live Server URL from your phone while phone and PC are on the same Wi-Fi, OR
- deploy to GitHub Pages/Vercel and open the public URL on Android.
